# Artwork production

Created with the built-in image generation tool. The promotional graphics are illustrations; the screenshot is a direct capture of live YouTube with the extension source running.

## Icon prompt

Create a simple transparent Chrome extension icon for YouTube Comments Closed: a navy rounded square, white widescreen frame and play triangle, and cyan close X; no words or third-party logos. Keep the mark legible at small sizes and use transparent outside padding.

## Wide promotional artwork prompt

Use case: ads-marketing. Asset type: Chrome Web Store small promotional tile for the extension 'YouTube Comments Closed'. Create a finished landscape graphic with an EXACT 11:7 aspect ratio (1760x1120 composition, exported later at 440x280). Use the supplied icon as the exact brand mark, preserving its white video frame and cyan close X on navy. Place it cleanly at right with generous padding; left half has large readable white modern sans serif typography. Text verbatim, exact spelling and no other text: 'YouTube' then 'Comments Closed' on separate lines, followed by smaller 'More room to watch.' Deep navy background with a subtle cyan light gradient and elegant sparse texture. Crisp calm professional utility product. No fabricated website UI, no screenshots, no people, no Google or YouTube logos, no red play-button branding, no watermark. Strong contrast and readable even at 440x280.

The tool returned a wide 2.5:1 composition, which was used for the optional marquee tile.

## Small promotional artwork prompt

Use case: ads-marketing. Asset type: SMALL Chrome Web Store promotional tile. Recompose the reference artwork into an EXACT 11:7 aspect-ratio rectangle, requested canvas 1760 wide by 1120 high, to be exported at 440x280. Maintain the navy/cyan palette and the exact icon from the reference. Use a compact two-column composition. LEFT: stack the title on THREE lines with exact words 'YouTube' / 'Comments' / 'Closed', with 'More room to watch.' below in smaller readable text. RIGHT: the large navy video-frame icon with cyan X. Keep all text and icon fully inside safe margins. The 11:7 canvas is taller and the title must be stacked so it fits. Clean professional marketing graphic, no other text, no fake browser screenshot, no trademark YouTube or Google logo, no people, no watermark.

## Final outputs

- store-icon-128.png: 128 x 128 PNG; icon padding normalized during size export.
- small-promo-440x280.png: 440 x 280 PNG.
- marquee-1400x560.png: 1400 x 560 PNG.
- screenshot-1280x800.png: 1280 x 800 PNG, direct browser capture.

Artwork source images are preserved. Promotional images were resized for the store's required pixel dimensions; no page screenshot was retouched. The original user screenshots were not edited.
